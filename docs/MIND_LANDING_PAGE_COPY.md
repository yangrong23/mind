## 价值主张（官网用 · §二）

**一句话：** 从信息的获取、整理、消化，到传播共享与成果交付 — 在 Mind 一站完成。

| 环节 | 海报句 |
|------|--------|
| 获取 | 订阅广场优质库，或把网页、文件、笔记收进来 |
| 整理 | 知识库管好碎片，图谱帮你看清脉络 |
| 消化 | 基于库精准问答，AI 洞察帮你想深一层 |
| 共享 | 团队共库协作，好内容发布到广场 |
| 交付 | 同一批信源，一键生成报告、播客与幻灯 |
