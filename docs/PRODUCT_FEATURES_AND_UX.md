# 产品功能与用户交互场景

本文档描述知识管理产品的**定位、能力分层、与当前客户端页面对应关系**，以及典型**用户场景与交互路径**。内容结合产品核心设想与现有界面（Memos / Notebooks / Clawbot / Me）的实际结构整理，便于产品、设计与研发对齐。

---

## 1. 产品定位与价值链条

产品面向「**从信息获取到消化再到利用**」的全链路，用 AI 降低摩擦、提高信噪比：

| 阶段 | 用户目标 | 产品能力（抽象） |
|------|----------|------------------|
| **获取** | 把线下/端侧高价值信息快速入库 | 录音、导入、设备采集；低打扰捕获 |
| **消化** | 理解结构、提炼要点、可行动化 | 转写、摘要、模板化加工、可视化（如思维导图） |
| **沉淀** | 决定长期保留并组织到主题库 | 移入知识库、智能推荐归属库、标签与来源管理 |
| **流通与再加工** | 在线上库内关联、衍生、协作 | 知识图谱、内容工厂、库内对话与引用 |
| **利用** | 把沉淀变成行动与分发 | 智能体任务链、与外部系统（IM 等）联动 |
| **自省** | 看见自己的认知模式与使用健康度 | 个性化洞察、使用强度与知识活动可视化 |

**线下上下文**（会议、灵感、设备录音）与**线上上下文**（文档、网页、库内对话）在「Me」层汇合，用于**个性化洞察**与**使用呈现**。

## 2. 模块与界面映射（当前 App）

底部导航与产品模块一一对应：

| Tab 名称（界面） | 产品角色 | 核心职责（与你描述的对齐） |
|------------------|----------|----------------------------|
| **Memos** | 收件箱 / 端侧捕获 | 接收端侧信息；快速智能分析（摘要、模板、后续可扩展思维导图等）；处理满意后**移入知识库**；推荐目标库 |
| **Notebooks** | 知识库（线上流通） | 笔记本列表；单库内 **Hub**（信源 + 库内对话 + 引用溯源）、**Graph**（知识图谱）、**Studio**（内容工厂） |
| **Clawbot** | 智能体 / 云端能力面 | 终端式执行反馈 + 技能开关；对接 **OpenClaw** 等云端能力，承担「利用层」的多类型任务 |
| **Me** | 个人中心 / 洞察 | 设备与词库、隐私策略；在融合线上线下上下文后呈现**个性化洞察**与**知识使用情况**（如活动热力、统计） |

**跨模块关键跳转（当前原型已实现或已预留入口）：**

- Memos → 笔记详情 → **Move to library** → 选择推荐/最近知识库 → 进入 **Notebooks** 内对应库详情。  
- Notebooks → 单库 **Ask** / 条目内 **Mind Agent** → 库上下文对话（含引用弹层）。  
- Clawbot → **Content factory** 快捷入口 → 跳转某库的 **Studio**。  
- 录音流程：Memos **Start recording** → 录音页 → 停止后进入 **笔记详情**。

## 3. Memos：端侧接收与快速消化

### 3.1 功能要点

- **捕获**：列表展示备忘录卡片（硬件/手机等来源）；支持进入录音流程；空状态引导开始记录。  
- **快速分析**：笔记详情内 **Summary / Transcript** 双视图；波形与播放；模板入口可对内容做结构化加工（与「基于模版处理」对齐）。  
- **手势与效率**：列表侧滑归档意向、删除等（与「快速处理」一致）。  
- **移入知识库**：详情顶栏 **Move to library**；选择库时展示**智能推荐**与最近使用，降低分类成本。  

### 3.2 典型交互场景

**场景 A：会后一条高质量录音**  
用户在 Memos 完成录音 → 打开详情查看摘要与转写 → 用模板生成会议纪要结构 → 判断需长期留存 → **Move to library** → 系统推荐「会议记录 / 产品库」等 → 确认后进入该 Notebook。

**场景 B：碎片灵感**  
快速记一条短内容 → 仅看摘要 Tab → 暂不归档；日后从列表滑动手势清理或再打开移入库。

**场景 C（规划）：思维导图**  
产品在描述中强调「思维导图」辅助消化；界面可在模板或独立 Tab 中扩展，与 Summary / Transcript 并列或作为模板输出类型。

## 4. Notebooks：线上流通、图谱与内容工厂

### 4.1 功能要点

- **笔记本列表**：按 Mine / Team / Following 等维度浏览；进入单库。  
- **单库 Hub**  
  - **信源**：横向快捷入口 + **全部文档**完整列表（标题、摘要、元数据），避免仅缩略图导致信息不完整。  
  - **库内对话**：基于「本库 N 个信源」提问；回答中带 **引用角标**，点击后半屏溯源（录音片段 / PDF 高亮等）。  
- **Graph**：知识图谱视图，表达实体与关系（直观化关联）。  
- **Studio（内容工厂）**：从库内素材衍生音频简报、幻灯、测验等可消费形态。  

### 4.2 典型交互场景

**场景 D：写 PRD 前复习资料**  
打开「产品库」Hub → 在 **All documents** 扫一遍条目 → 点进单篇看全文 → 回到对话区问「和版本 X 需求冲突的点？」→ 点击 **[1]** 查看引用片段。

**场景 E：周报素材一站式产出**  
在同一库打开 **Studio** → 选择「音频简报 / 幻灯」等 → 消费工厂产出物（与「进一步加工消化」对齐）。

## 5. Clawbot：云端 OpenClaw 与多智能体利用

### 5.1 功能要点

- **终端式执行流**：展示调用链路与状态（如接口调用成功后的反馈），对应「可观测的自动化」。  
- **技能库**：按技能开关能力；部分技能可配置（如 API Key、Notion 等），与「连接外部系统」方向一致。  
- **与 Memos / Notebooks 的关系**：利用已捕获与已沉淀的结构化内容，执行**开发、同步、分发**等任务（见下节场景）。  

### 5.2 典型交互场景（含规划能力）

**场景 F：开发智能体**  
用户选定知识库中的产品设计文档 → 在 Clawbot 启用「代码/实现」类技能与对应智能体 → OpenClaw 拉取文档结构与设计约束 → 输出实现草案或仓库级变更建议（产品目标：设计思路 → 产品实现）。

**场景 G：IM 联动（规划）**  
配置 IM 连接器技能 → 会议结束后触发「把 Memos 摘要同步到指定 IM 频道」或「把库内定稿文档发到 IM」→ 终端显示同步结果。  

**场景 H：多智能体分工**  
不同 Agent 负责研究、写作、开发、运营触达；用户从侧栏或广场选择 Agent 进入对话；任务可引用 Notebook 范围。

## 6. Me：个人上下文与洞察呈现

### 6.1 功能要点

- **设备孪生**：电量、存储时长等设备侧信号，强化「端侧捕获」与账号的绑定感。  
- **词库（Lexicon）**：领域术语偏置转写与检索，提升「线下专业内容」识别质量。  
- **隐私与离线**：全离线模式及确认说明，与云端 Claw 能力降级策略一致。  
- **洞察与使用可视化**：热力图、连续天数、笔记量等；Daily review / AI insights 等入口，承载「个性化个人洞察」。  

### 6.2 典型交互场景

**场景 I：周回顾**  
用户打开 Me → 查看活动热力与统计 → 进入 Daily review / AI insights，阅读基于本周 Memos + Notebooks 行为的总结与建议。

**场景 J：科研/垂直领域用户**  
在 Lexicon 批量导入 CSV 术语 → 后续 Memos 转写与 Notebooks 检索自动偏向这些词。

## 7. 端到端用户旅程（串联）

```text
线下/端侧捕获（Memos）
    → 快速消化（摘要 / 模板 / 导图…）
    → 决策沉淀（Move to library + 智能推荐）
线上组织与再加工（Notebooks：文档 / 对话 / 引用 / 图谱 / 内容工厂）
    → 任务化利用（Clawbot + OpenClaw：开发、IM、分发…）
个人反馈闭环（Me：洞察 + 使用可视化 + 词库与设备上下文）
```
