## 二、使用案例引导教程（IMA 原文 · 勿改写）

> 页面结构：角色卡片 → **查看指引** → 场景说明。以下为报告原文，**逐字保留 ima**。

### 个人角色（「你可以这样用 ima」）

**大学生**  
课程学习时，导入课件、课堂笔记等学习资料，ima 可帮你总结知识要点，生成播客或可视化脑图，便于快速掌握课程知识。

**教师**  
备课时，调用知识库中积累的教学材料，ima 可结合课程知识生成教案及课件，提升教学质量，辅助课题研究。

**分析师**  
行业研究时，导入调研信息、会议录音、专家访谈、市场政策等，ima 可生成行研报告，辅助分析决策。

**律师**  
代理诉讼时，导入案件细节、法律法条等，ima 可总结关键事实和争议焦点，生成可视化的案情脉络，并辅助撰写诉讼状等文书材料。

**企政职员**  
企政办公时，导入政策文件、会议材料、工作笔记等，ima 可精准解读政策并辅助公文写作，提升工作效率。

**创作者**  
内容创作时，导入热点话题、相关资讯等，ima 可生成内容提纲和创意脚本，激发创作灵感，提升内容生产效率。

### 组织 / 共享场景（「共享知识库可以这样用」）

**公共服务咨询**  
整合各类政策、通知、常见问题至 ima 知识库，ima 可 24 小时响应用户提问，成为公众的 AI 客服，提升答疑响应速度。

**企业知识共享**  
将分散的经验、数据转化为可复用的知识资产，通过知识库实现知识共享，每位员工可精准获取并高效应用相关知识。

**班级教学辅导**  
教师上传教学板书、高频考点、易错题解析、重难点知识等，学生可随时通过知识库自主提问，有针对性地掌握学科知识。

**小组课题协作**  
组员分头调研收集资料，结合 ima 知识库分析课题难点并确定研究主题，基于课题目标辅助生成课题大纲。

**推荐三段式（Medrix 官网 About，自有文案）：**

1. **采集**：会议、实验记录、文献 PDF、补充材料 — 移动端快速入库，Web 端系统整理。  
2. **Grounded 智能**：知识库与 Mindar 打通，问答与任务**只基于你已授权的信源**，召回可核对，降低幻觉。  
3. **交付**：综述提纲、方法学段落、汇报幻灯、组会播客 — Studio 从同一套文献库一键产出。

### 科研向宣传语句库（Medrix 自有，与 IMA 语料分开投放）

**品牌 / 价值**

- 科研人员的第二文献库，也是可对话的文献库。  
- **先建库，再提问** — 用你自己的论文与数据对话，而不是用模型的幻觉。  
- 把「读过」变成「可查、可引、可交付」。  
- Medrix：让 AI 回到**证据链**上，而不是回到猜测上。  
- 在「会思考的知识库」之上，为**科研场景**补上可核验、可引用。（*语气延伸，非改写 IMA 官方句*)  

**知识库 × 智能体（科研语境）**

- 基于课题知识库精准问答，**Mindar 按文献自主整理与交付**。  
- 精准召回你库内的论文段落与实验记录，**深度综合 + 原文溯源**。  
- 文献综述、开题报告、基金本子 — **复杂写作任务，基于同一知识库交付**。  
- 课题组的 copilot：**越用越懂你的研究方向与写作习惯**。  

**协作 / 实验室**

- 实验室的共享大脑 — **课题信源一处维护，全员同一套引用标准**。  
- PI 建库定范围，学生上传实验笔记与文献，**组会前统一 Ask**。  
- 私域知识库权限分级，**适合课题组、科室与联合实验室**。  

**学术诚信（对外合规表述）**

- 生成内容**默认附带依据摘录**，便于人工核对（非代写，是辅助）。  
- 支持跳转原文，**鼓励引用而非复制**。  
- 团队库操作可审计（规划），满足课题组管理需求。

### 5.1 内容工厂（Studio）宣传语料

> 宣传手法参考 IMA：**「基于知识库处理复杂任务，自主交付结果」** + **「一键生成多种知识产物」**（§一 #15–16）。Mind 产品对应：库详情 **Studio** Tab、Mindar 工厂横条、任务队列与归档回 Hub。

| 层级 | 宣传语（Mind 对外） |
|------|---------------------|
| 模块标题 | **内容工厂 — 基于知识库，自主交付你要的成果** |
| 副标题 | 复杂任务不用从零写，**同一批信源**完成生成 |
| 展开（IMA 式长句） | 将库内碎片信息整合为**研究报告**，把长文与访谈沉淀为**音频简报**，从文献与笔记生成**汇报幻灯、闪卡与测验** — Mind 帮你**一键产出**多种可交付形态，并支持归档回知识库继续引用。 |
| 能力 bullet | 研究报告 · 音频简报 · 视频简报 · 幻灯 · 闪卡 · 测验 · 信息图（以实际上线类型为准） |
| 与 Mindar | 对话里选好资料范围，**工厂与 Mindar 同源知识库**，避免「聊完再另找素材」 |
| 科研语境 | 组会前 **Studio 出简报**，写作前 **Studio 出综述提纲**，证据仍回到 Hub 溯源 |

**短句（海报 / 功能卡）：**

- **信源在库，成品在工厂。**  
- **不是多一个模板，而是多一条交付线。**  
- **问在 Hub，做成在 Studio。**  
- **报告、播客、幻灯 — 从同一知识库长出来。**  

**使用案例引导（IMA 式一句）：**  
整理完文献与会议材料后，在**内容工厂**选择报告或音频简报，Mind 将基于该库信源生成可汇报的成品，并可将结果**归档回 Hub** 供团队继续问答与引用。

### 5.2 演进式知识图谱（Graph）宣传语料

> 宣传手法参考 IMA：**「会思考的知识库」** + 私域 **「知识共建、关系可见」**。Mind 差异化：**图谱随入库演进（evolving）**，而非静态示意图。

| 层级 | 宣传语（Mind 对外） |
|------|---------------------|
| 模块标题 | **演进式知识图谱 — 知识入库，关系生长** |
| 副标题 | 不止看见条目列表，**看见概念如何相连** |
| 展开（IMA 式长句） | 每新增一篇文献、一条笔记或一次上传，图谱中的**实体与关联持续更新**；在 Hub 精读，在 Graph **俯瞰脉络**，再回到 Ask 或 Studio 做判断与交付。 |
| 演进（evolving） | **Evolving graph** — 随资料入库自动延展；支持触发重建（团队库/管理员） |
| 与 Hub / Studio | **Hub 读原文，Graph 看结构，Studio 出成品** — 三视图同一知识库 |
| 科研语境 | 课题综述前用 Graph **摸清概念簇**；跨文献假设用 Graph **找缺口与重复** |

**短句：**

- **列表是档案，图谱是地图。**  
- **库越用越厚，图越用越清。**  
- **演进式图谱：你的知识在生长，而不是躺在文件夹里。**  
- **从「搜到一篇」到「看见一片」。**  

**使用案例引导（IMA 式一句）：**  
导入一批论文与实验记录后，打开**知识图谱**查看主题、方法与结论如何关联；新信源入库后图谱**持续演进**，再针对薄弱节点在 Hub 追问或送入内容工厂生成综述。

## 七、Mindar 专项宣传语料（Mind 自有 · 非 IMA）

### 7.1 功能向

| 场景 | 宣传语 |
|------|--------|
| 首页 | **Mindar — 绑库工作的 Copilot** |
